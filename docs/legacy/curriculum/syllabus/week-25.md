# Tuần 25

**Thuộc:** Objective 3: Lập trình Game Client (60 FPS) & Frontend Web (React 10+ screens)
**Mục tiêu thời gian:** ~30 giờ
**Tỷ lệ AI/Human:** 50% AI - 50% Human (Human thiết kế State, AI hỗ trợ Scripting)

---

## 🎯 Focus (Trọng tâm học tập)
Code Game Client bằng [Unity C#](https://learn.unity.com/) (Tối ưu 60 FPS) và Admin Dashboard bằng [React.js](https://react.dev/learn) (10+ màn hình). **Mô phỏng Teamwork:** Đóng vai cả Backend Dev & Frontend Dev để đẩy Git chéo, xử lý Merge Conflicts và tự Review Code (Cross-functional Roles).

## 📚 Tài liệu & Chứng chỉ cần đạt
- **HackerRank: Không yêu cầu.**
- **LeetCode: Chuyển sang giải các bài liên quan đến Graph/BFS/DFS ứng dụng cho Game ([Tham khảo](https://leetcode.com/studyplan/top-interview-150/)).**
- **Coursera: Khóa [Microsoft Full-Stack Developer](https://www.coursera.org/professional-certificates/microsoft-full-stack-developer) (Tuần 6 của chứng chỉ).**

## 💻 Nhiệm vụ Thực hành & Code
- Thực hiện nghiêm túc tỷ lệ Human/AI của tuần này.
- Bám sát lộ trình bài giảng của Coursera hoặc LeetCode.
- Code và hoàn thiện các module của Game Idle RPG theo Focus.
