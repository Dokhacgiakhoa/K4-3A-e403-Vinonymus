# 1000 Hours Human Learning with AI - Master Roadmap

Lộ trình này được thiết kế để đưa một người học từ con số 0 (hoặc cơ bản) đến cấp độ **Full-stack Developer tích hợp AI**, với kỹ năng cốt lõi là sự linh hoạt đa ngôn ngữ (Python, Java, C#).
Dự án được tư liệu hóa dưới dạng **"Build in Public"** với 100 video YouTube chia sẻ kiến thức.

Dự án Capstone: **Phát hành Game Idle RPG (Unity C# Client + Java/Python Backend + AI) lên App Store & Google Play.**

---

## 📅 Chiến lược Thời gian (Chạy nước rút 9 tháng)
*Thời gian dự kiến: Lộ trình kéo dài 9 tháng liên tục.*
Tổng cộng ~38 Tuần, áp dụng cơ chế "Khởi động êm ái, Về đích bùng nổ".

1. **Tháng thứ 1 - Tháng thứ 3 (Warm-up Phase):** ~20 giờ/tuần (Tương đương **2 video/tuần**). Tổng ~240 giờ.
   - *Mục tiêu:* Xây dựng nền tảng tư duy, không để bị "ngợp".
2. **Tháng thứ 4 - Tháng thứ 6 (Accelerating Phase):** ~30 giờ/tuần (Tương đương **3 video/tuần**). Tổng ~390 giờ.
   - *Mục tiêu:* Code cường độ cao, làm quen với áp lực dự án thực tế.
3. **Tháng thứ 7 - Tháng thứ 9 (Intensive Phase):** ~30-40 giờ/tuần (Tương đương **3-4 video/tuần**). Tổng ~370 giờ.
   - *Mục tiêu:* Sống cùng code, tối ưu hóa game, hoàn thiện video, chuẩn bị đưa sản phẩm ra thị trường.

> **Quy tắc Build in Public:** Cứ mỗi **10 giờ học/code**, sản xuất **1 Video YouTube**. (Tổng 1000 giờ = 100 Video).
> 
> **💡 Triết lý Quản trị Thời gian (OKRs):** Không chia nhỏ KPI theo từng ngày để tránh áp lực (burnout). Khối lượng công việc được giao khoán theo **TUẦN**. Người học hoàn toàn tự chủ phân bổ thời gian (cày tập trung vào cuối tuần hoặc chia đều các ngày), miễn là ngày Chủ Nhật check-in tiến độ đạt 100% Key Results của tuần đó.

---

## 🗺️ Hành trình OKRs Chi Tiết

### 🎯 Objective 1: Thiết lập Tư duy, Cấu trúc Dữ liệu cơ bản (Tháng thứ 1 - Tháng thứ 2)
**Ngân sách thời gian:** 200 giờ.
*Trọng tâm: Xây dựng thói quen, logic cốt lõi và làm chủ GitHub.*

*   **Key Result 1.1 (Thói quen):** Đạt 100% tỷ lệ commit code hàng ngày lên GitHub. Setup quy trình làm việc chuẩn (IDE, Git, Markdown).
*   **Key Result 1.2 (Giải thuật cơ bản):** Vượt qua 30/150 bài LeetCode ở mốc Easy/Medium (Tập trung: Array, String, Hashmap, Linked List, Dynamic Programming). Tự viết Big O Analysis cho mỗi bài.
*   **Key Result 1.3 (Chứng chỉ):** Thi đỗ 3 Chứng chỉ **HackerRank Basic** (Python, Java, SQL).

### 🎯 Objective 2: Lập trình Hướng đối tượng & Xây dựng Core Backend (Tháng thứ 3 - Tháng thứ 4)
**Ngân sách thời gian:** 250 giờ.
*Trọng tâm: Xây dựng bộ não của hệ thống (Microservices, DB).*

*   **Key Result 2.1 (Kiến trúc Backend):** Thiết kế và code xong 3 Microservices độc lập (Sử dụng Java Spring Boot hoặc C# .NET Core).
*   **Key Result 2.2 (Database & API):** Xây dựng hệ thống 50+ RESTful APIs chuẩn REST. Database Schema (PostgreSQL) đạt chuẩn Normalization với 20+ Tables.
*   **Key Result 2.3 (Chứng chỉ):** Hoàn thành chứng chỉ **IBM Full Stack Software Developer** (Coursera) và HackerRank C# Basic.

### 🎯 Objective 3: Lập trình Game Client & Frontend Web (Tháng thứ 5 - Tháng thứ 6)
**Ngân sách thời gian:** 250 giờ.
*Trọng tâm: Giao diện người dùng và Trải nghiệm Tương tác.*

*   **Key Result 3.1 (Chứng chỉ):** Hoàn thành chứng chỉ **Microsoft Full-Stack Developer** (Coursera).
*   **Key Result 3.2 (Game Client):** Hoàn thiện Core Gameplay của Game Idle RPG trên Unity (C#). Tối ưu hóa đạt **60 FPS** trên thiết bị di động. Xử lý State Management mượt mà.
*   **Key Result 3.3 (Web Dashboard):** Phân tích và code **1 Admin Dashboard Web** bằng React.js chứa ít nhất **10+ màn hình (screens)** kết nối thời gian thực với server để quản lý game.

### 🎯 Objective 4: Tính năng App Nâng cao (Monetization & Retention) (Tháng thứ 7 - Tháng thứ 8)
**Ngân sách thời gian:** 150 giờ.
*Trọng tâm: Thương mại hóa Game (IAP, Ads, Offline Logic).*

*   **Key Result 4.1 (Tính năng cày cuốc):** Xây dựng hệ thống **Offline Progress** (tính toán lượng EXP và đồ rơi ra trong thời gian User tắt App). Tích hợp Social Login (Google/Apple).
*   **Key Result 4.2 (Monetization):** Tích hợp SDK kiếm tiền: **In-App Purchases (IAP)** để nạp thẻ và **Unity Ads / AdMob** để xem quảng cáo nhận thưởng. Sử dụng AI Copilot để sinh 80% code cấu hình SDK.

### 🎯 Objective 5: Tối ưu hóa Database, Phát hành App Store & Tổng kết (Tháng thứ 9)
**Ngân sách thời gian:** 150 giờ.
*Trọng tâm: Launching & Portfolio.*

*   **Key Result 5.1 (Performance):** Tích hợp Redis Caching, tối ưu hóa Database Indexes để API Response Time đạt mức **< 50ms**.
*   **Key Result 5.2 (Phát hành):** Cấu hình CI/CD (GitHub Actions). Publish thành công Game lên **Google Play Store** và **Apple App Store**.
*   **Key Result 5.3 (Tổng duyệt DSA):** Hoàn thành nốt mục tiêu 100 bài LeetCode. Mock Interview thực chiến.
*   **Key Result 5.4 (Portfolio):** Hoàn thiện **1 Website CV Cá nhân** tổng hợp toàn bộ Source Code, Game, và Chứng chỉ.
