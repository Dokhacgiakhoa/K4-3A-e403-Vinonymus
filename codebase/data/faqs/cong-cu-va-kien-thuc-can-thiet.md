- **Thứ tự ưu tiên trang bị kiến thức (Rate theo P)**:
  - **P0 (Bắt buộc & Quan trọng nhất)**: Khả năng tự học tập với AI, kỹ năng vibecode với AI, kỹ năng làm việc nhóm và networking.
  - **P1**: Kiến thức về phát triển sản phẩm, coding cơ bản, thành thạo sử dụng Git/GitHub.
  - **P2**: Kiến thức nền về AI (học nắm chắc các khái niệm cốt lõi / keywords như LLM, RAG, Agent).
- **Quy trình Setup môi trường ban đầu**:
  - **Bước 1**: Tải **Antigravity** (Google Antigravity IDE / CLI) về máy, tập thao tác làm quen.
  - **Bước 2**: Tải Python, Node.js, Git... biết cách thiết lập môi trường phát triển và quản lý API keys.
- **Bộ công cụ AI Coding khuyến nghị theo tài chính**:
  - **Lựa chọn mạnh nhất (Ưu tiên hàng đầu)**: **Claude Code** (Claude 3.7 Sonnet / Pro) hoặc **Codex**.
  - **Lựa chọn tối ưu chi phí (Dành cho Sinh viên / Người mới)**: **Antigravity** (chi phí rẻ hơn chục lần so với Claude/Codex nhưng đáp ứng rất tốt nhu cầu).
  - **Lựa chọn thay thế khác**: Cursor, VS Code kết hợp với GitHub Copilot (đều rất tốt và phù hợp).
